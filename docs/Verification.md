# 0.1.5 验证范围

0.1.5 为预览版。2026-10-17（Asia/Shanghai）完成离线测试；实机运行验收待完成。[English guide](../README.en.md)

## 可重复验证

完整构建需要 .NET 10 SDK 和受支持的本地 Dinkum 安装：

```powershell
./scripts/build.ps1 -GamePath 'C:\Games\Dinkum'
```

完整流程编译插件与管理工具，执行 **87 组离线测试** 和管理工具临时目录隔离测试，生成 ZIP、SHA256 及 `dist/build-verification-0.1.5.json`。构建不启动游戏、不安装插件、不写真实存档。

无需游戏的独立测试为 **86 组**：

```powershell
dotnet run --project tests/DinkumSaveProtection.Tests -c Release
```

提供游戏目录后增加 1 组只读程序集兼容检查，总计 87 组。检查不会加载执行游戏程序集。

## 测试覆盖

- 快照编码、深复制、完整性、损坏与中断、分支、保留策略、异步合并、身份和退出元数据。
- 主动退出和异常断线的会话资格、客户端重启、旧缓存与冲突处理、适配器主线程和幂等约束。
- 原版数据预检、早期与角色生成后恢复阶段、缺失对象及失败来源保留。
- 原版导出字段映射、世界和未知顶层记录保留、未知嵌入字段拒绝、光标与装备打包、避免重复物品、扩展字段保留。
- 临时文件原子提交、源文件和身份并发变化、暂存损坏、故障注入、中断对账、落后及分叉缓存拒绝覆盖。
- 管理工具的缺少加载器、重复 GUID、安装/升级/回滚/卸载、文件被改动，以及其他 Mod、加载器、配置和非受管文件保留。

测试使用原创内存替身和临时目录；通过测试不等于真实 Unity、网络和 ES3 环境已经通过验收。

## 发布检查

- Release 编译无警告、无错误，完整离线测试及临时安装隔离测试通过。
- 仅从公开文件导出的干净目录完成构建，不依赖本机额外资料。
- 源码不包含游戏程序集、存档、私人配置、缓存或日志。
- 安装包仅含本插件、安装清单、管理工具、MIT 及公开文档；不含加载器和游戏依赖。
- ZIP 的 SHA256 与发布附件一致，构建回执记录本次测试数量及包哈希。
